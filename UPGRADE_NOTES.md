# Udaan Frontend v2 Upgrade

Adds:

- Google Sign-In button in the navbar.
- Account dashboard.
- Persistent profile display.
- Match history display.
- Save Scheme and Save Scholarship buttons.
- Authenticated match calls automatically save profiles and history.

## GitHub Pages environment

The frontend needs:

- `VITE_API_URL=https://udaan-final-backend.onrender.com`
- `VITE_GOOGLE_CLIENT_ID=<same Google OAuth client ID used on Render>`

For the current repository the Vite base remains `/udaan-final-frontend/`.
