# Udaan Frontend v8 — Dashboard Sidebar On/Off

- Added a desktop Dashboard On/Off control in the top header.
- Dashboard Off hides the full left sidebar and expands the website content to full width.
- Dashboard On restores the left sidebar.
- The preference is saved in localStorage (`udaan:dashboard-sidebar`) so it remains the same after refresh.
- Mobile keeps the existing hamburger open/close behavior.
- No existing matching, authentication, chatbot, theme, language, EMI, or portal functionality was removed.
